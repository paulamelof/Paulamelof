### ✦ sobre mim

Sou técnica em Informática pelo **IFRN** e estudo **Tecnologia da Informação na UFRN (IMD)**.
Trabalho com suporte de TI e, no dia a dia, levanto requisitos, acompanho testes e escrevo scripts em Python e SQL para automatizar processos internos. Foi aí que percebi o que gosto de fazer: **construir sistemas que resolvem problemas de verdade**.

- 🎯 **Foco:** back-end com **Java + Spring Boot**
- 🎨 **Diferencial:** UX, pensando em quem vai usar o sistema
- 🤖 **Complemento:** desenvolvimento com IA e automação de processos
- 🌱 **Aberta a:** estágio em desenvolvimento back-end
